# git-practice

A small repository for practicing Git and GitHub.

## Files

- `hello.py`: prints a greeting.
- `calculator.py`: demonstrates basic arithmetic functions.
- `notes.txt`: short learning notes.
- `git_commands.md`: a quick Git command reference.
- `.gitignore`: keeps generated files and local secrets out of Git.

## Run the examples

```bash
python hello.py
python calculator.py
```

This project is for learning purposes.
