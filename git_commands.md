# Git command quick reference

```bash
git status                 # Show the current working-tree state
git add <file>             # Stage one file
git add .                  # Stage all non-ignored changes
git commit -m "message"   # Save a commit
git log --oneline          # Show commit history
git remote -v              # Show configured remote repositories
git push -u origin main    # Push the main branch to GitHub
```

Make sure `git status` looks as expected before committing or pushing.
